## Conventions

- ADRs are numbered sequentially.
- Status values: Proposed, Accepted, Deprecated, Superseded.
- Business behavior remains defined in [PRODUCT_REQUIREMENTS.md](../PRODUCT_REQUIREMENTS.md).
- API contracts remain defined in [API_SPEC.md](../API_SPEC.md).
- Data models remain defined in [DATABASE.md](../DATABASE.md).
